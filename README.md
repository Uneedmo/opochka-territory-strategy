# Опочка — стратегия развития территории

Одностраничное исследование и предложение Дмитрия Мо.

Статический сайт: HTML, CSS и JavaScript. Публикуется в GitHub Pages из корня ветки main.

Срез исследования: 15 октября 2026 года. Цены аналогов и продуктовые гипотезы сопровождаются оговорками и источниками.

## Фотографии

Фотографии Опочки взяты из Wikimedia Commons. Авторы, даты, источники и лицензии указаны под снимками и в [assets/photo-credits.json](assets/photo-credits.json). Файлы фотографий сохраняют соответствующие лицензии CC BY-SA 4.0, CC BY-SA 3.0 или CC0. В макете используется кадрирование.

## Карта

Интерактивная карта Google загружается с сервиса Google Maps. Есть ссылка на Яндекс Карты. Точное положение участка проекта пока не нанесено.
