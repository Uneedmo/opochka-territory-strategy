# Как читать реестр

Файл `Реестр_отзывов.csv` — журнал отбора 178 карточек. Дата сбора: 15.10.2026. Полные тексты отзывов не распространяются; ссылка и ориентир позволяют найти исходное высказывание. Объём корпуса не означает такое же число подтверждённых клиентов.

## Поля

- `id` — внутренний номер карточки, используемый в отчёте.
- `object` — объект размещения/отдыха.
- `date_display` — дата публикации в том виде, в котором её показал источник. Год не восстановлен по предположению.
- `time_group`: R — явно указанная дата в последние два года; H — исторический контекст, включая новый отзыв о старой поездке; D — год карточки не показан. Это не обязательно дата самого проживания.
- `screening`: K — сохранено для качественного анализа/контекста; X — исключено. Причина исключения — в соседнем поле.
- `visit_type`: DAY — явно дневной визит; OTHER — консультация/отдельная услуга; S — остальное, включая проживание и случаи, где формат не уточнён. S не доказывает ночёвку.
- `source_access`: page — текст страницы; indexed_extract — индексированное поисковое извлечение.
- `partial_extract` — обнаружена неполнота доступного текста. Отсутствие флага не гарантирует, что прочитан весь исходный отзыв.
- `reported_repeat`: SELF — автор сообщает о собственном состоявшемся повторном посещении; OTHER — говорит о повторных посещениях других людей; U — не установлено. SELF не является независимой проверкой поездок.
- `topic_candidates` — вспомогательные автоматические метки: N — природа/тишина; C — комфорт; F — питание; H — персонал/забота; A — занятия; P — цена; T — организация/связь/дорога; R — возможное упоминание повторов; I — возможное намерение вернуться. Возможны ложные срабатывания. Они не заменяют чтение и не являются основанием для статистики мотивов.
- `source_url` — ссылка на источник; у Алтуна часть карточек относится к другому корпусу того же имения.
- `locator` — имя автора и дата для поиска в источнике. Для ECO-006 исправлен соединённый заголовок извлечения: автор Ri.
- `text_fingerprint` — короткий технический отпечаток использованного фрагмента, не идентификатор человека.

## Ограничения

У разных площадок разная доступность и порядок вывода отзывов. Агрегаторы могут повторять отзывы с карт; между источниками одного объекта повторы удалялись по автору/дате, один близкий повтор дополнительно исключён. Полная проверка уникальности авторов между всеми объектами не проводилась.

Формулировки о здоровье, шумах, качестве обслуживания, оплате или недостатках — утверждения авторов. Их истинность независимо не установлена. Нельзя использовать этот реестр для медицинских выводов, рейтинга объектов или расчёта распространённости проблем на рынке.
